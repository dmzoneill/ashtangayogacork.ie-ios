# Ashtanga Yoga Cork for iOS

The iOS app for the Ashtanga Yoga Cork studio, a client for the studio's
booking site.

## What it does

- Signs students in, including social login.
- Shows classes, prices and the student's profile in tabs.
- Shows bookings, class credits and credits that are about to expire.
- Handles purchases, receipts and vouchers.
- Includes a settings screen and a bug reporter.

## Tech

- Swift and SwiftUI
- Xcode project: `Ashtanga Yoga Cork.xcodeproj`

## Building

Open `Ashtanga Yoga Cork.xcodeproj` in Xcode and run the
`Ashtanga Yoga Cork` target on a simulator or device.
